# ניהול מכירת ארבעת המינים

המכירה מתקיימת פעם בשנה לפני סוכות. העמוד הציבורי הוא `/arbaat-haminim`.
מניהול האתר נכנסים ל״ארבעת המינים״, או ישירות ל־`/admin/arbaat-haminim`.

זהו מסך ניהול אחד. עורכים את שנת המכירה, הסטים והמחירים, התוספות, התמונה, שעות ותאריכי המכירה, פרטי האיסוף והשאלות הנפוצות. אפשר לבדוק תצוגה מקדימה ואז ללחוץ ״שמירת שינויים באתר״. השמירה מעדכנת את העמוד הציבורי מיד. בשנה הבאה מעדכנים את אותם השדות, בלי ליצור או לשכפל רשומה.

מחירים אינם מוצגים כרגע בעמוד הציבורי, גם כאשר נשמר מחיר באדמין. תמונה ניתנת להחלפה בנתיב באתר או בקישור HTTPS. הטופס פותח WhatsApp למספר 0537700339 עם שם, סט, כמות, תוספות, אופן קבלה והערה. אין שדה טלפון. בחירת הסט והתוספות מופיעה פעם אחת, בטופס רציף; אופן קבלה מוצג לבחירה רק אם הוגדרו כמה אפשרויות. הלקוח שולח את ההודעה בעצמו. אין סליקה או שמירת הזמנה בשרת.

הנתונים נשמרים במסמך יחיד `current`, במודל `ArbaatHaminimSettings`. נשמר שם האוסף הקודם כדי לשמר תוכן ציבורי שכבר נשמר. נתוני טיוטות ישנים אינם נמחקים, אך אינם בשימוש. API הניהול כולל GET ו־PUT בלבד, מוגן בהתחברות המנהל הקיימת ובבדיקת מקור הבקשה. מספר גרסה מונע דריסת שינויים מחלון אחר.

יש לפרוס שרת ולקוח יחד. אין צורך בהגדרות סביבה חדשות. הטיפוס נמצא ב־client/src/types/arbaatHaminim.ts וב־server/src/types/arbaatHaminim.ts, ואימות הנתונים נמצא בשרת.

## תצוגת ההזמנה הפשוטה

העמוד מציג תמונה, בחירת סט, כמות וכפתור WhatsApp. התוספות נפתחות לפי רצון המשתמש. אין שדות שם, טלפון, הערה או אופן קבלה, ואין FAQ. ההודעה כוללת את הסט, הכמות והתוספות שנבחרו; מחיר ואיסוף מתואמים בשיחה. נתוני התוכן הנוספים נשארים שמורים באדמין אך אינם מוצגים בתצוגה המצומצמת.
