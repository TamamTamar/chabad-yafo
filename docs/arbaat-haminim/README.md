# ארבעת המינים — ניהול עונות

העמוד הציבורי: `/arbaat-haminim`.
ניהול: ניהול האתר ← ארבעת המינים, או `/admin/arbaat-haminim`.

## עבודה שוטפת

1. בכניסה הראשונה מוצגת תבנית תשפ״ז. שמירת טיוטה יוצרת עונה במסד הנתונים.
2. עורכים שנה, טקסטים, תיאור SEO, תמונה, סטים ומחירים, תוספות, אפשרויות קבלה, פרטי מכירה ושאלות נפוצות.
3. מחיר ריק מוצג כ״מחיר יעודכן״. תוספת שנבחרה היא יחידה אחת לכל ההזמנה.
4. שומרים טיוטה ובודקים תצוגה מקדימה. השמירה אינה משנה את התוכן הציבורי.
5. ״פרסום עונה זו באתר״ מפרסם עותק של הגרסה השמורה. העונה הקודמת נשארת ברשימת העונות.
6. לשנה הבאה: מזינים שנה ובוחרים ״שכפול לעונה חדשה״. המחירים, פרטי המכירה, אפשרויות האיסוף, FAQ ותיאור SEO מתאפסים לערכי הכנה. שאר הטקסטים והתמונה מועתקים ויש לבדוק אותם. שומרים ומפרסמים רק כשמוכנים.

השמירה משתמשת בגרסה למניעת דריסת שינויים מחלון אחר. במקרה של התנגשות יש להעתיק את השינויים הרצויים, לרענן ולטעון את הגרסה העדכנית.

## תשתית ומגבלות

- `ArbaatHaminimSeason`: עונה וטיוטתה האחרונה. אין היסטוריה מלאה של כל עריכת טיוטה.
- `ArbaatHaminimPublication`: עותק ציבורי יחיד, המתעדכן אטומית בפרסום.
- API ציבורי: `GET /api/arbaat-haminim`. API מוגן: `/api/admin/arbaat-haminim`.
- המסך משתמש בהתחברות המנהל הקיימת ובבדיקת מקור בקשות לשינויים.
- יש לפרוס גם את השרת וגם את הלקוח. ללא פרסום ראשון מוצגת תבנית ההכנה. בכשל API בפרודקשן מופיעה הודעת אי־זמינות; תבנית מקומית בכשל זמינה רק בפיתוח ומסומנת כך.
- סליקה והזמנות עדיין מושבתות. אין שמירת לקוחות או הזמנות ואין אפשרות להפעיל סליקה מתוך ניהול התוכן. המשך חיבור הזמנות צריך להשתמש בתשתית נדרים הקיימת, בתמחור בצד השרת ובאימות תשלום.
- תמונות מוחלפות בנתיב באתר או בקישור HTTPS; אין העלאת קבצים במסך הזה.
- טיפוס התוכן נמצא ב־`client/src/types/arbaatHaminim.ts` וב־`server/src/types/arbaatHaminim.ts`; יש לעדכן את שניהם יחד ואת אימות השרת.

## אימות

בניות לקוח ושרת, ESLint לקבצים שנגעו בהם, בדיקות אימות נתונים והרשאות, ואינטגרציה מול MongoDB מקומי מבודד. בדיקות דפדפן: תמונת הפתיח, שמירה, פרסום, שכפול ואיפוס מחירים, תצוגה מקדימה והפרדתה מהתוכן הציבורי.

בדיקת אינטגרציה אופציונלית (מסד בדיקות חדש בלבד; הבדיקה מוחקת אותו בסיום):

```sh
ARBAAT_TEST_MONGO_URI=mongodb://127.0.0.1:27029/arbaat_qa_seasons node --test server/dist/tests/arbaatHaminim.test.js server/dist/tests/arbaatHaminimRoutes.test.js
```
